# Portfolio redesign starter

Static HTML/CSS/JS portfolio designed for GitHub Pages. No theme, Jekyll, build step, or paid hosting required.

## Publish on GitHub Pages
1. Replace `YOUR NAME`, email, links, and project content.
2. Commit and push to the `port-redesign` branch.
3. In GitHub: Settings → Pages → Deploy from a branch → select `port-redesign` and `/root`.
4. If your repository is a project site, your URL will be `https://USERNAME.github.io/REPOSITORY/` and relative links in this starter will work.
